# Calculate afferent and efferent couplings between packages

Calculate afferent and efferent couplings between packages

## Usage

``` r
couplings(x, year = 2015, summarise = TRUE)
```

## Arguments

- x:

  Result of
  [load_pkgstats_data](https://mpadge.github.io/pkgstats-analyses/reference/load_pkgstats_data.md).

- year:

  Year for which coupling data are to be obtained

- summarise:

  if `TRUE`, convert full `data.frame` of results to summary statistics.

## Value

The results
